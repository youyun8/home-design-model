# 住宅 3D 多角度導覽

依 16 張施工圖面（天花板圖、空調圖、平面圖、立面圖、地板材質圖、水電圖、電燈圖）建立的 **18 坪住宅 3D 導覽網站**，
並加入一台**可自動進水、需拉水線的賀眾牌桌上型冰溫熱飲水機**。

純靜態網站（HTML + JavaScript modules + three.js），沒有建置步驟，也不需要下載任何圖檔——所有貼圖都由程式即時生成，離線也能開。

## 開啟方式

```bash
python3 -m http.server 8080      # 或任何靜態伺服器
# 瀏覽器開啟 http://localhost:8080
```

> 需要支援 WebGL2 的瀏覽器（近年的 Chrome / Edge / Safari / Firefox）。不能直接用 `file://` 開啟（ES module 限制）。

部署到 GitHub Pages：Repository → Settings → Pages → Source 選 `Deploy from a branch`，分支選此分支、資料夾 `/ (root)` 即可。

## 功能

| 模式 | 說明 |
| --- | --- |
| **環景** | 剖視式 dollhouse：自動隱藏面向鏡頭的外牆與天花板，可旋轉／縮放／平移，點擊門片可開關。 |
| **漫遊** | 第一人稱，`W A S D` 移動、拖曳轉向、`Shift` 加速、滾輪前後；牆與家具碰撞；手機有虛擬搖桿。 |
| **自動導覽** | 依序介紹各空間，任何操作即可接手。 |
| **視角列表** | 空間總覽、玄關、客廳（電視牆／沙發背牆）、廚房、飲水機、拉水線、主臥、衣櫃、書房、衛浴、後陽台。 |
| **日夜／燈光** | 白天（午後陽光透過窗戶與陰影）、黃昏、夜晚；全室與**各房間**嵌燈開關，燈光不會穿牆。 |
| **小地圖** | 顯示目前位置與視野，點擊即可傳送。 |
| **畫質** | 高（AO + MSAA + 4096 陰影）／中／省電，手機預設省電。 |

### 自動進水飲水機（賀眾牌桌上型）

* 機型：UW-672AW-1 桌上冰溫熱（880 W）／UR-672BW-1 桌上溫熱（750 W），可在面板切換。
* 尺寸 寬 32 × 深 48 × 高 52 cm，熱水 3.5 L、溫水 2.0 L、冰水 1.1 L（依提供的規格圖）。
* 位置：廚房北側檯面，爐台與水槽之間，正上方就是濾心櫃，方便拉水線。
* 取水：直接點機身上的「冰／溫／熱」鈕（按住出水，輕點一杯 250 ml），或使用右側面板。
  取水會出現水柱、杯中水位與熱水蒸氣。
* **自動進水**：取水後水位一下降，進水閥自動開啟補水，補滿後關閉；熱水箱因進冷水降溫後會「加熱回溫」
  （時間為示意加速）。可「透視機身內部」查看三個水箱、加熱管、冷媒壓縮機與進水電磁閥。
* **水線**：冷水角閥 → 三通（一路回水槽龍頭）→ **UP-206 雙道濾芯（UF-1 → UF-556）** → 3/8" PE 管穿過檯面束環 →
  飲水機進水口；旁邊預留**專用插座**（110 V，圖面註明面板為古銅外框＋黑）。
  按「顯示水線」或選「拉水線（櫃內配管）」視角會自動開櫃門，並標示各零件。

## 圖面對照與假設

幾何尺寸取自平面圖標註（房寬、櫃體深度、門窗寬度等），並以公分為單位重建；
立面圖提供櫃體尺寸、層板高度、燈帶與材質備註。**材質、顏色與家具造型再依 8 張設計效果圖校正**：

* **牆面**：電視牆與玄關（門口）為暗灰司曼特水泥漆，其餘牆面為**玫瑰白**。
* **客廳**：橄欖綠絨布沙發配米色布克蕾坐墊、橡木壁板沙發背牆（圓形赤陶壁燈、觸控面板、長虹玻璃細窗）、
  橄欖綠橫梁、黑色電視櫃搭橡木抽屜與弧形櫃門、落地窗配灰色紗簾、淺米色大地磚。
* **玄關**：深梅紫格紋大門、四門橡木鞋櫃（貓掌孔）、暖灰色六角磚降落塵區、拱形深色鏡。
* **主臥**：橡木床頭板（橫向木紋）與 LED 燈帶、低矮雙床、灰褐色圓角床頭櫃、橡木衣櫃（門片間細黑縫）、
  木框扶手椅與圓邊几、斑馬簾、淺色木地板。
* **書房**：牆面全為玫瑰白；開放書架（LED 層板）與橡木櫃、靠東牆書桌、洞洞板、細橫葉簾、橄欖綠降板、兒童椅。
* 窗戶改為**落地窗**（黑色鋁框），僅後陽台為高窗。

圖面與效果圖都沒有標示、或無法判讀處為合理假設，以**示意**處理：

* 窗型與分格、外牆與柱體外型、窗簾長度與褶數。
* 家具軟件：床品、抱枕、書本、桌上物件、廚房小物、泰迪熊與蘑菇燈等小物。
* 廚房爐台上方未畫抽油煙機，因此未建模。
* 天花板造型（降板 252／280／270／240）依 A0 天花板圖；軟頂範圍與分割線為推估。
* 衛浴五金、馬桶與浴櫃外型為通用造型。
* 飲水機外觀為依產品圖建模的示意造型，實際以實機為準。

`js/data.js` 集中放平面資料（房間、嵌燈位置、視角），修改後重新整理即可看到結果。

## 專案結構

```
index.html              頁面骨架與 UI
css/style.css           介面樣式（含手機版面）
js/main.js              啟動、渲染器、後製（AO / Bloom）、主迴圈
js/data.js              圖面資料：房間、嵌燈、視角
js/core.js              座標轉換、世界 UV 方塊、房間燈光連結（light linking）
js/textures.js          程式生成貼圖：木地板、地磚、六角磚、水磨石、塗料、天空
js/materials.js         PBR 材質庫
js/architecture.js      牆、地板、天花板、窗、門（可開關）
js/furn-*.js            各房間家具與櫃體（living / bedroom / study / rooms-b）
js/decor.js             從效果圖建出的小物件：斑馬簾、壁燈、洞洞板、床頭櫃、扶手椅、蘑菇燈…
js/dispenser.js         飲水機模型、水箱模擬、水線與濾芯
js/lighting.js          日夜、嵌燈（SpotLight）、環境光
js/navigator.js         環景／漫遊／導覽相機與碰撞
js/ui.js, interaction.js  面板、小地圖、點擊／按住互動
js/optimize.js          靜態網格合併（降低 draw call）
vendor/three/           three.js r170（含用到的 addons）
```

## 技術備註

* 每個房間的嵌燈只照亮自己的房間（修改 three.js 光照 shader，以頂點 `aRoom` 屬性做 light linking），
  不需要為 20 盞燈各做一張陰影貼圖。
* 靜態家具與建築依材質合併成少量網格；可動物件（門、飲水機）保持獨立。
